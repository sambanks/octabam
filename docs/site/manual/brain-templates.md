*BRAIN: Templates*

A template stores a reusable setup. Use **LEFT / RIGHT** to choose the **KIT**, **MIDI**, or **PROJECT** tab.

1. Select **NEW** and press **YES** to create a template.
2. Enter a name and confirm with **YES**.
3. Select the saved template to open its actions and values.
4. Choose **APPLY TO…** to apply it, or **SET AS DEFAULT** to use it as a starting point. **CLEAR DEFAULT** removes that assignment.

The template screen also provides **SAVE**, **RENAME**, and **DELETE**.

- KIT templates hold a whole Part, applied by section and track: FX, LFO, SRC, AMP, MIDI TRACKS, SCENES, MACHINES.
- MIDI templates store a MIDI track's pages.
- PROJECT templates cover the stock PROJECT / CONTROL / MIDI screens. SET AS DEFAULT on one makes it the settings of every new project.

KIT templates leave the project's sample slots and levels unchanged. A KIT template covers the SRC and AMP pages of every machine type. A KIT template is a Kit's Part (the KITS module saves a Part per Kit); it applies to the current Part. Applying a KIT template lets you choose the whole Part, a section across tracks, or a source and destination track. A KIT default supplies Part Clear and the Parts of a new project.

Use **LEFT / RIGHT** or the encoder to edit values. **NO** returns to the previous screen; unsaved edits prompt **SAVE CHANGES?**. A name already in use is refused.

## Page shortcut

A page shortcut saves and loads the page in front of you as a template: hold a page key (SRC, AMP, LFO, FX1, FX2) and press FUNC. The list that opens has SAVE FX DEFAULT, CLEAR FX DEFAULT, SAVE TEMPLATE, LOAD TEMPLATE, DELETE TEMPLATE (plus NAME KNOB on a MIDI track). On an FX1 or FX2 page it has SAVE FX DEFAULT and CLEAR FX DEFAULT only: effects have no templates. On an MKII, FUNC + a push of the LEVEL encoder opens TOOLS > LOAD.

**SAVE FX DEFAULT** stores the current FX page as the default for that effect when it is newly selected. **CLEAR FX DEFAULT** removes the stored default. **SAVE PROJECT** updates its recovery copy.

On a MIDI track, **NAME KNOB** gives each of the ten assignable CCs a label of up to four characters on CTRL1 and CTRL2. An empty name clears it.
