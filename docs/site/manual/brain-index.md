*BRAIN in the main menu*

BRAIN is the on-unit menu for shared settings, defaults, templates, performance information, logs, and switching between images. Open it from the MAIN MENU: select **PROJ**, then **BRAIN**. Use **UP** and **DOWN** to move through the list, **YES** to open or change the selected item, and **NO** to return to the previous screen.

The list contains **TEMPLATES**, **REMIXES**, **SETTINGS**, **PERFORMANCE**, **LOG**, and **ABOUT**. Each has its own page below.
