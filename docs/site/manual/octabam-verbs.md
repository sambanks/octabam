### About Octabam Verbs

Octabam Verbs is [Octabam](../octabam/index.md) with one difference: VERBERATION in place of the
three stock reverbs. Everything else is Octabam's: BRAIN, Kits, page-2 locks and scenes, MIDI
and USB, the sequencing and recording features, OCTA-303, and SPECTRUM, CHARACTER, MODULATION,
SHATTER and COMPRESSOR's side-chain, loaded on demand. Three more effects, VIBRATO, TRANSIENT and
RESONATOR, are always loaded, in the words the stock reverbs gave up. SCOPE and the WAVE
machine are not in this image. This is version 0.5.

### What changes on the unit

- **The reverbs.** PLATE REV, SPRING REV and DARK REV are off both effect menus. FX2 lists
  [VERBERATION](effects/verberation.md) and three rows that start it in a mode: VERB PLATE,
  VERB ROOM and VERB HALL. VERBERATION goes from rooms to halls and has a desk-style gate; its
  page 2 holds MODE, LCUT, MOD, RATE, SIZE and PRE.
- **Old Parts.** A Part saved with a stock reverb opens on that reverb's row, with the row's
  defaults on its FX2 pages.
- **Three resident effects.** [VIBRATO](effects/vibrato.md) (FX1 and FX2),
  [TRANSIENT](effects/transient.md) (FX1 and FX2) and [RESONATOR](effects/resonator.md)
  (FX1 only) are always loaded, like a stock effect.
- **No reverb guard.** In Octabam the choosers refuse a stock reverb over loaded effect code.
  Here VERBERATION can sit on any track's FX2 beside any loaded effect.

Where Octabam keeps every stock effect as stock has it, this remix does not.

### Status

This remix ran on Sam's MKII on 22 Nov 2026, booted by REMIX SWITCH from the flashed image (not flashed itself): the pre-flight
checks pass and 32 program changes between MODULATION, SPECTRUM and BASE left none unapplied. The effect and loader layouts, kits,
scenes and DIRECT_JUMP (toggle off) ran on the earlier BUILD 05. DIRECT_JUMP with the toggle on and the 56-minute soak did not run.
The DARK REV fault described in the Octabam manual needs the stock DARK REV, which this remix does not carry; it was not run here.

### Before you install

Back up the CF card first. Kits write a file into each project they load.
A project made on the unit after installing needs no preparation. To return
to stock OS, follow [Safety and Recovery](../../../safety.md).
