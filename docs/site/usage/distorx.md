DISTORX puts two distortion pedals into a single insert effect: the **BOSS
SD-1** Super OverDrive and the **Pro Co RAT**, plus the Turbo RAT as a third
mode, each modelled from its circuit component values. MODE selects the pedal;
changing it crossfades briefly through the dry signal (about 3 ms), so a scene
or parameter lock can switch pedals without a click. It was designed with a
TB-303 line in mind, but works on any source.

## Access

Select a track, press FX1 or FX2, and choose DISTORX from the effect list.

## Operation

MODE defaults to **OFF**, passing audio through untouched so you can add
DISTORX to a track in the middle of a set. Turn MODE to SD-1, RAT, or TURB to
fade a pedal in. IN controls how hard the track drives the pedal, DRIV sets the
pedal's gain, TONE shapes brightness (clockwise is brighter in every mode), and
LEVL sets the output level after the pedal. Setting MIX to 0 gives an exact dry
passthrough.

## Parameters

| Knob | Default | What it does |
|---|---|---|
| LEVL | 64 | Output level; 64 roughly matches the input loudness at DRIV 64 in every MODE |
| TONE | 64 | SD-1 TONE / RAT FILTER: 0 is dark, 127 is bright |
| DRIV | 64 | SD-1 DRIVE (18–47 dB) / RAT DISTORTION (0–67 dB) |
| IN | 0 | Input gain into the pedal, −12 to +12 dB |
| MIX | 127 | Dry/wet mix: 127 is the pedal alone, 0 is an exact passthrough |
| MODE | OFF | OFF, SD-1, RAT, or TURB (the Turbo RAT's red LEDs) |
