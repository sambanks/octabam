Loop one 16-step page of one track while you edit it; the rest of the
pattern plays on, and the track comes back in time.

## Access

In GRID RECORDING, hold PAGE and tap trig 1, 2, 3 or 4 to loop that page of
the current track. The same combo again stops it. Not in an official remix;
build the test remix `page-loop`.

## Operation

- A toast shows LOOP PAGE n, LOOP OFF, or NO SUCH PAGE when the pattern is
  shorter than that page.
- One track loops at a time; it keeps looping when you change tracks or leave
  GRID RECORDING, and stops on a pattern or bank change.
- When the loop ends, the track is exactly where it would have been.
- Audio and MIDI tracks both loop.
- With a loop on, the first step after PLAY plays the pattern's first step;
  the page loops from the second step on.
- PAGE + trig no longer places a trig and flips the page (stock); PAGE + REC,
  PLAY and STOP are unchanged.
