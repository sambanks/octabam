## What it does

DARK MODE inverts the Octatrack's entire display output into a high-contrast OLED-style dark theme (white text and graphics on deep black), covering every page, window, menu, and popup.

## How to use it

1. Open **MAIN MENU > BRAIN > SETTINGS > DARK MODE**.
2. Toggle **DARK MODE** on (`1`) or off (`0`).
3. The setting applies live (`Apply.LIVE`) without requiring a reboot.

## Notes

- On an Octatrack MKI (transflective STN display), dark mode reduces visual smearing and makes track lanes and fine parameter text significantly easier to read.
- If subtle horizontal ghosting or shadow trails appear on MKI hardware, lowering the hardware LCD contrast 1–2 notches in `[PROJECT] > SYSTEM > PERSONALIZE > LCD CONTRAST` sharpens the pixels.
