This module lets you toggle QUANTIZE LIVE REC directly from the front panel
without opening the PERSONALIZE menu.

## Operation

Hold [REC] and tap [PLAY] to display the current setting in a toast
(`LIVE REC: QUANTIZED` or `LIVE REC: UNQUANTIZED`). Tap [PLAY] again while the
toast is visible to switch the setting. If PERSONALIZE is open, its QUANTIZE
LIVE REC check mark updates immediately. The first [REC] + [PLAY] press still
starts live recording, as on stock firmware.

Changes made this way survive a power cycle.
