## What it does

Toggles QUANTIZE LIVE REC from the front panel, without the PERSONALIZE
menu.

## How to use it

Hold [REC] and tap [PLAY]: the setting shows in a toast. Tap [PLAY]
again while the toast is up to invert it. The first [REC] + [PLAY] still
starts live recording, as on stock.

A setting changed this way survives a power cycle.
