BUSDELAY is the bus delay engine, permanently assigned to track 1's FX2 slot (locked so the FX2 chooser cannot replace it). It offers three modes: CLEAN, GRAIN (a pitched granular cloud over the delay lines), and REVERSE, with tape wow applied to the loop tap in all modes. Delay repeats output on track 1 and can also be routed into the bus reverb via the reverb's DLY knob. The delay follows the project tempo.

## Access

Track 1's FX2 page displays only DEL and REV. All other parameters are in the TEMPO window: press [TEMPO], then use LEFT and RIGHT to select the DELAY box.

## Adjust the sound

- On track 1, DEL sends track 1's dry signal into the delay, and REV sends it into the reverb.
- TIME controls the delay time as a free dial that gently snaps to tempo divisions.
- FDBK sets feedback, TONE adjusts loop brightness, PING controls ping-pong stereo bounce, and WET sets the wet output level.
- MODE selects CLEAN, GRAIN, or REVRS:
  - In **GRAIN** mode, SCTR sets how far apart the grains read, DENS controls grain density (level-compensated), SIZE selects the grain length (GLEN 46 / 93 / 23 ms, or XTRM 186 ms), and PTCH shifts pitch by ±2 octaves (64 is unison; holding a MIDI note overrides PTCH).
  - In **REVERSE** mode, SIZE sets the segment length (SLEN, with XTRM = 371 ms). The output is mono and PING is forced off.

## Parameters

| Page | Knob | Function |
|---|---|---|
| 1 | DEL | This track's dry send into the delay |
| 1 | REV | This track's dry send into the reverb |
| 1 | FDBK | Feedback |
| 1 | TONE | Loop tone |
| 1 | PING | Ping-pong; forced off in REVERSE |
| 1 | WET | Wet level |
| 2 | MODE | CLEAN / GRAIN / REVRS |
| 2 | SCTR | GRAIN: how far apart the grains read |
| 2 | DENS | GRAIN: density, level-flat |
| 2 | SIZE | GRAIN: grain length 46 / 93 / 23 ms, XTRM 186 ms. REVERSE: segment length, XTRM 371 ms |
| 2 | PTCH | GRAIN: ±2 octaves, 64 = unison |
| 2 | TIME | Delay time; sticky-snaps to tempo divisions |
