VCA160 is a compressor modeled from the schematic of the 1976 **dbx 160**
compressor/limiter. Its true-RMS detector provides the 160's program-dependent
attack and release without separate attack or release knobs. KEY lets the
detector follow any track's level published by KEYBUS, so a kick on one track
can duck a bass line on another.

## Controls

| Page | Knob | What it does |
|---|---|---|
| 1 | THRS | threshold, −50 to 0 dBFS RMS |
| 1 | RATI | ratio: 1:1 at 0, 2:1 at 50, 4:1 at 75, 120:1 at 100; above 100 on to −1:1 |
| 1 | OUT | output gain, ±20 dB |
| 1 | KEY | OFF (this track) or T1–T8 (that track's level) |
| 1 | MIX | dry/wet; 0 = exact passthrough |
| 2 | KNEE | HARD (the 160) or OVER (a soft knee, as on the 160A) |

VCA160 uses its own effect ID rather than replacing a stock effect ID, though
the remix still needs to free code space for it (for example, by removing
PLATE REV). Any remix with VCA160 also includes KEYBUS to publish the track
levels that KEY reads.

## A first patch: the kick ducks the bass

1. Put a kick on T1 and a bass on T5.
2. On T5, select VCA160 in FX2 (or FX1).
3. Set KEY to T1 and RATI to about 75 (4:1), then lower THRS until the bass
   dips on every kick. Use OUT to bring the level back up.
4. For a softer pump, set KNEE to OVER on page 2 or lower MIX below 127.

With KEY set to OFF, it works as an ordinary 160 on its own track using THRS
and RATI, with program-dependent attack and release.
