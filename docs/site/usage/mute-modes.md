MUTE MODES lets you choose how muted or soloed-out audio tracks behave. The
default setting, OT, matches stock firmware.

## Access

Open PERSONALIZE > MUTE MODE, on the second row after PREVIEW WITHOUT FX. The
setting survives a power cycle.

## Modes

| Mode | What happens |
|---|---|
| OT | stock behavior: instant cut after the FX |
| OTFX | dry sound cuts, FX tails ring out, and the sequencer keeps running |
| OTFX-T | same as OTFX, with new trigs suppressed |
| DT-T | sounding note plays out on its amp envelope, with new trigs suppressed |

## Notes

- A muted track used as a COMPRESSOR KEY continues feeding the compressor as
  on stock firmware, including SIDECHAIN COMPRESSOR when installed.
- If a track is already muted when you switch MUTE MODE away from OT, it keeps
  OT's cut until you unmute it, so any note triggered while muted under OT is
  never heard.
