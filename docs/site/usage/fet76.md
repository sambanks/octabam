FET76 is a limiter modelled on the **UREI 1176LN** FET limiting amplifier
(1967). It models a FET gain cell in a feedback loop with a fixed threshold
driven by INPUT, the four ratio buttons plus ALL BUTTONS IN, attack times down
to 20 microseconds, and a two-capacitor release that recovers quickly from
short peaks and more slowly from sustained limiting. Its author uses it as the
final stage on the master track.

## Access

Select a track, press FX1 or FX2, and choose FET76 from the effect list.

## Controls

| Page | Knob | What it does |
|---|---|---|
| 1 | INPT | Input gain, −30 to +30 dB (more input increases limiting) |
| 1 | OUTP | Output gain, −30 to +30 dB |
| 1 | ATK | Attack time, 800 microseconds (1) to 20 microseconds (127); 0 = OFF |
| 1 | REL | Release time, 1.1 s (0) to 50 ms (127) |
| 1 | RATI | Ratio: 4:1, 8:1, 12:1, 20:1, or ALL |
| 1 | MIX | Dry/wet mix; 0 = exact passthrough |
| 2 | REV | Revision: LN or BLUE (more 2nd harmonic) |

As on the original hardware, there is no threshold knob: raise INPT for more
limiting, and use OUTP to set the output level afterward.
