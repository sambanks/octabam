Part of the effect loader (the other half is Effect loader (copier)). SPECTRUM, CHARACTER and MODULATION are not kept in the effects processor all the time: the loader brings one in while a track uses it and takes it out when none does. This half sends the code to the processor in small pieces. It has no controls and nothing on the panel.

## What you will notice

- Until the code arrives, about 25 ms after you choose the effect, the effect passes the audio through.
- A pattern change that puts one of these effects on all eight tracks, or takes it off them, leaves about 0.34 s of silence at the switch.
- Choosing a stock reverb (PLATE, SPRING or DARK) on the FX2 slot that shares its memory with a loaded effect is refused with a message, and so is the reverse. A song that sets both another way leaves the reverb or the effect dry, and says which at the next page key.
