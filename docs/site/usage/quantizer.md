Set a scale and root for pitch controls and chromatic keys. The settings are
stored with the project and survive a power cycle.

## Set the scale, root, and glide

In PROJECT > CONTROL > SEQUENCER, this module adds three rows: SCALE (OFF,
followed by 24 scales), ROOT (C through B), and GLIDE (OFF, or 1..127).

## What the settings control

- The PTCH knob, parameter locks, and CHROMATIC trig keys snap to the selected
  scale and root.
- Key 1 of the CHROMATIC keyboard plays the root note.
- On a sample track, the keyboard spans one complete root-to-root octave.
- GLIDE sets the slide time for legato on both synth tracks and sample tracks
  (controlled by the LEG option on AMP SETUP).
- On a synth track with VOIC set to 2–4, polyphonic chromatic keys also snap
  to the scale.
- SCALE, ROOT, and GLIDE survive a power cycle.
