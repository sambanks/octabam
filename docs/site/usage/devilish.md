This module adds Robin Whittle's **Devil Fish** modifications to [OCTA-303](octa303.md) tracks. When you load dEVILish into FX1 or FX2 on an OCTA-303 track, its twelve knobs control circuit modifications inside the 303 voice, including oscillator drive into the filter, filter FM, key tracking, envelope times, and slide. Default settings match a standard TB-303. On tracks that are not using OCTA-303, it does nothing.

## Access

Select an OCTA-303 track, press FX1 or FX2, and choose dEVILish from the effect list. It replaces PHASER in both FX1 and FX2 menus.

## Controls

| Page | Knob | What it does |
|---|---|---|
| 1 | OVDR | Overdrive: VCO level into the filter (25 matches a stock TB-303) |
| 1 | FM | Filter FM from the VCA output |
| 1 | TRCK | Filter key tracking |
| 1 | VDEC | Volume decay, up to endless sustain |
| 1 | SLID | Slide time (60–360 ms) |
| 1 | ADEC | Filter decay for accented notes (30 ms–3 s) |
| 2 | SATK | Soft attack on non-accented notes |
| 2 | SWP | Resonance sweep mode: ACID (stock 303), WHST, or SELF (allows self-oscillation) |
| 2 | SPD | Accent sweep speed: FAST, NORM, or SLOW |
| 2 | MUFF | Muffler distortion: OFF, SOFT, or HARD |
| 2 | CUTX | Extended filter cutoff range |
| 2 | ENVX | Tripled envelope modulation range |

Page 1 parameters respond to parameter locks, scenes, the crossfader, and LFOs like any standard effect.
