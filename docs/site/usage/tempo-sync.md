TEMPO SYNC links the bus delay to the project tempo using the stock tempo
clock. The delay's TIME knob displays a tempo division (such as `1/8`) when
set to a musical subdivision, and milliseconds otherwise.

## Operation

There is no menu; it works automatically wherever the bus delay runs. MIDI
notes held on the delay track's channel are forwarded to the delay, and in
GRAIN mode they set the grain pitch in place of PTCH.
