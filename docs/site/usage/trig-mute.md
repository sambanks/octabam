# TRIG MUTE

Module author: [Hteah](https://github.com/Hteah). PR preparation and gate by 8thmyth.

ColdFire module: mute and unmute individual trigs in GRID RECORDING. The module
source and its gate (`verify_trig_mute.py`) are in this branch; the test remix
is `remixes/test/trig-mute/`. Proof is emulator-only in this branch — no
hardware result is claimed here.
