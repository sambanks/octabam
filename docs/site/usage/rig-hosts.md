New Parts are pre-configured with the send bus routing already in place:
track 1's FX2 is set to the bus delay, track 5's FX2 is set to the bus reverb,
track 8 (the master track) uses the stock DELAY (for Echo Freeze beat repeat),
and every other track's FX2 is set to SEND. Projects created on the unit are
ready to use the bus without extra setup.
