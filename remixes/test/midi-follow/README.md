# MIDI Follow

MIDI Follow, STORE and EVENTS with stock audio effects. Followers keep their own
rhythm and transposition while taking native notes from another MIDI track. Settings
belong to the native Part; RFOL defaults OFF.

Tested in the emulator, including routing, register choices and MIDI note releases.
This standalone selection has not been tested on hardware. MKII tests of a USB
MIDI variant include sustained seven-follower playback and an eight-audio-track
run, with an unresolved failure at a higher native MIDI load; see the module
[verification report](../../../modules/midi-follow/DEVELOPMENT.md#mkii-usb-midi-load-tests-30-october-2026).

See [MIDI Follow controls](../../../modules/midi-follow/README.md).
