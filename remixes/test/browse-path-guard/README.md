# `browse-path-guard` -- BROWSE PATH GUARD

One ColdFire module by Sam Banks and the stock effects.

## What is in it

- **BROWSE PATH GUARD** -- [`modules/browse-path-guard/README.md`](../../../modules/browse-path-guard/README.md).

## Build

```bash
make image REMIX=test/browse-path-guard BUILD=1
```

[BUILDING.md](../../../docs/guide/BUILDING.md) is the walk-through from a fresh machine to a flashed unit. `make check REMIX=test/browse-path-guard` runs every gate first.
