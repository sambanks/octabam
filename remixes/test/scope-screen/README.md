# scope-screen

Minimal stock-FX remix for capturing the LCD over SysEx while trying SCOPE.

| | |
|---|---|
| SCOPE | DOWN+TEMPO (TUNER still on UP+TEMPO) |
| SCREEN | answers Elektron's screenshot SysEx (`screendump`) on DIN or USB |
| USB | so USB-MIDI screendump works |

Not a full stack handoff (no BRAIN / REMIX SWITCH / CORE). Load from a BRAIN-capable tip, or flash as a one-off probe.
