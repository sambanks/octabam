# hooks (test remix)

REC THRESHOLD and FREE LOOP in one image, with STORE (which FREE LOOP saves through)
and the stock effects. Alone, the pair would be refused: both replace the track status
icon renderer's state-cache load. The registry appends
[HOOKS](../../../modules/hooks/README.md), which owns the site and calls each module's
own routine, REC THRESHOLD's blink first, then FREE LOOP's mark.

Until REC_TRIG_MUTE's pin moved past `553d8d2` this remix was MORPH, REC_TRIG_MUTE and
REC THRESHOLD; REC_TRIG_MUTE's mute dots now sit beside the tab's machine letter and no
longer share a site, and MORPH has had no partner on the [TRACK] key layer since that pin.

`tools/verify/verify_hooks.py hooks` runs the bridged status-icon chain and decodes the
[TRACK]-layer table under Unicorn from the modules' own sources, and checks this image's
site once it is built.

## Where it has run

Not flashed. Under Unicorn only (verify_hooks).
