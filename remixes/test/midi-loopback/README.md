# MIDI Loopback

MIDI Loopback and STORE with stock audio effects. Press CHAN on MIDI NOTE
SETUP to choose EXT, INT or BOTH per track and Part. Fresh Parts use EXT.

This STORE-based selection has run in the emulator. Hardware validation of the
new Part service remains outstanding.
