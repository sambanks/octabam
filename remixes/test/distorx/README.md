# `distorx` — DISTORX alone

DISTORX on FX1 and FX2, beside the stock effects. Its 1,629 words (code and
table, v10) need one run that long: CHORUS + PLATE REV + SPRING REV give theirs
(1,743 words up to the SPRING REV words DARK REV still calls), so DARK REV
stays (`modules/distorx/README.md` "Where it goes").

`make check REMIX=distorx`.

**Hardware:** the owner's MKI, image DTXPR3 (BUILD 96, on `0x05`), and before
it DTXPR1 (BUILD 91, on `0x0a`), (module README "On the unit").
