# remix `vibrato`

Carries `VIBRATO` on FX1 for its render gates and the hardware check image.
Not a shipping remix. PLATE REV gives up its words (VIBRATO's code is 563 of
its 594; the 103-word table goes in PLATE REV's X data).

**This test remix has not been flashed**; the module ran on a unit in Bryan
T's `_bt_oct` (`modules/vibrato/README.md`, "On the unit"). The check on a
unit: every page-1 knob and SHP's
four positions on FX1, a SHP change while playing (the duck), SLEW at 0 and
127, WID on SQR and on RND, an FX2 instance (a dry pass), and four FX1
instances on one core (tracks 1-4 or 5-8).
