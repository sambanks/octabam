# MIDI Loopback with MIDI Scenes

MIDI Loopback, MIDI Scenes and USB on the stock effects, with
[MIDI LOOPBACK SCENES](../../../modules/midi-loopback-scenes/README.md), the
bridge that sends each MIDI track's scene CCs where its DEST sends its notes.
STORE carries both modules' Part state.

See [Loopback's controls and storage](../../../modules/midi-loopback/README.md)
and [MIDI Scenes](../../../modules/midi-scenes/README.md).
