# lazy-chop

Stock effects with LAZY CHOP and BUFFER SAVER (and ATA WRITE GUARD, as `buffer-saver` carries it): chop a sample or a recorder take by tapping the trig keys, and save it with its slices. LAZY CHOP's gate runs here; the module ran on 8thmyth's MKI in `test/octabam-lazy-chop` (OCTABAMHC, 14 Nov 2026).
