# `lofi2` -- LOFI2

LOFI2 beside 12 stock effects (all but PLATE REV and SPRING REV, whose words it takes: LOFI2 is 856 words and a 516-word table, PLATE REV alone 594).

## What is in it

- **LOFI2** -- [`modules/lofi2/README.md`](../../../modules/lofi2/README.md).
- the stock effects but PLATE REV and SPRING REV, listed so the chooser is otherwise stock's, stock LO-FI included for A/B.

## Status

`make check` on this tree. The module ran on Bryan T's MKII as images 96-99 (October 2026) inside his own remix; this remix has not been flashed.

## Build

```bash
make check REMIX=lofi2
```
