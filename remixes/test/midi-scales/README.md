# MIDI Scales

MIDI Scales with all fourteen stock effects and fallback NONE. Adds seven-mode
KEY selection to native MIDI ARP SETUP. Follow, Harmony and Loopback are not selected.

Runs in the emulator and was tested on Octatrack MKII with OCTABAMS1 on
16 October 2026; [test scope and limitations](DEVELOPMENT.md#hardware-evidence).

See [controls and storage](../../../modules/midi-scales/README.md).
