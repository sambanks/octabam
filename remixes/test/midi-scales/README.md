# MIDI Scales

MIDI Scales with all fourteen stock effects and fallback NONE. Adds seven-mode
KEY selection to native MIDI ARP SETUP. No other MIDI module is selected.

Runs in the emulator and was tested on Octatrack MKII with OCTABAMS1; [test scope and limitations](DEVELOPMENT.md#hardware-evidence).

See [controls and storage](../../../modules/midi-scales/README.md).
