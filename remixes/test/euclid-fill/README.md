# `euclid-fill`

STORE + EUCLID FILL and the stock effects.

- **STORE** -- required: EUCLID FILL is an `euclid.work` client.
- **EUCLID FILL** -- [`modules/euclid-fill/README.md`](../../../modules/euclid-fill/README.md).
- the 14 stock FX2 effects, listed so the chooser is stock's.
