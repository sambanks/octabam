# test/drummer

DRUMMER alone with STORE (drummer.work), over the stock effects: the remix
its gates run on. `modules/drummer/verify_port.py` plays the user's sliced
loop on a DRUMMER track and checks every voice start against the engine;
`verify_store.py` edits a kit on the panel, saves the project and boots on
the saved card; `verify_drk.py` saves a kit file beside the sample and loads
it back; `shots_ui.py` and `shots_kit.py` capture the machine row,
both pages and the KIT window. Run on the author's MKII, images 52-78
(November 2026).
