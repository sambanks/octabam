# `arr-row-cap` -- ARR ROW CAP

One ColdFire module by Sam Banks and the stock effects.

## What is in it

- **ARR ROW CAP** -- [`modules/arr-row-cap/README.md`](../../../modules/arr-row-cap/README.md).
- the 14 stock FX2 effects, listed so the chooser is stock's.

## Build

```bash
make image REMIX=test/arr-row-cap BUILD=1
```

[BUILDING.md](../../../docs/guide/BUILDING.md) is the walk-through from a fresh machine to a flashed unit. `make check REMIX=test/arr-row-cap` runs every gate first.
