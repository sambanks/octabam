# remix `tuned-comb`

Carries `TUNED COMB` on FX1 for its render gates and the hardware check image.
Not a shipping remix. PLATE REV and SPRING REV give up their words: one run of
1,657, where TUNED COMB's code (1,166) and table (175) go.

The check on a unit: every page-1 knob on FX1, plain and with FUNC held; LP
swept at a held note (the pitch holds); FB across 64 (the octave down); an LFO
on FINE and on LP; an FX2 instance (a dry pass); and four FX1 instances on
one core (tracks 1-4 or 5-8).
