# `octatrick` — Tim Hastie's six modules with USB MIDI and USB audio out and in on the stock effects

One remix with everything: SYNTH MACHINE, SY DRUM, SCALE QUANTIZER, DIRECT JUMP, TUNER and PROCESSOR LOAD from [timhastie/octatrick-modules](https://github.com/timhastie/octatrick-modules) (the submodule under `modules/synth`, `modules/sy-drum`, `modules/quantizer`, `modules/direct-jump`, `modules/tuner` and `modules/processor-load`, pinned to `v2.14` (`39dc5d8`) = Octatrick 2.14, 13 Oct 2026), with USB MIDI and USB AUDIO OUT TRACKS MAIN CUE (markandrus, [octemu](https://github.com/markandrus/octemu); the 20-channel output as it is on main today) and USB AUDIO IN ABCD with USB CROSSBAR (Bryan T: the computer's audio comes in on inputs A, B, C and D). No octabam DSP code: thirteen of the fourteen stock effects are listed with fallback NONE, the `usb-io-tracks-main-cue-abcd` pattern, so their DSP code, their dispatch and their chooser rows stay stock. SPATIALIZER is gone from both effect menus because the USB audio input needs a few of a stock effect's DSP words for its inject and takes SPATIALIZER's, as Sam's `usb-io` remixes do; a project that selects it plays that slot as NONE. Until 29 Sep 2026 this was three remixes (`octatrick`, `octatrick-usb`, `octatrick-tuner`); the subsets served nobody, so they are one. SY DRUM and PROCESSOR LOAD joined at 2.11 (9 Oct 2026); the modules they declare conflicts with (KITS, PLOCKS P2, STEM REC; CF METER, TEMPO BUS) are not in it, nor LOAD METER (the same frame-interrupt epilogue as PROCESSOR LOAD; the ledger refuses the pair on that site).

## What is in it

- **SYNTH MACHINE** — FM SYNTH in the track's machine list (the row after PICKUP in SRC SETUP and SELECT MACHINE TYPE, since 2.10; no sample, no marker file), or any FLEX track whose sample is named FMSYNTH*.wav (a silent 4 s marker file will do; SYNTH*.wav is still accepted, and the marker's length never ends the note) plays a two-operator FM voice instead of the sample: PLAYBACK page PTCH RATO INDX FINE FDBK DEC (PTCH in semitones, FINE in cents), on the LFO page VOIC (1 = mono, 2..4 = paraphonic) and CHRD (32 chord shapes, each with three inversions on the knob, lockable per step, snapped onto SCALE and its ROOT). Since 2.9 the engine owns the AMP envelope (ATK / HOLD / REL from the AMP page, applied with the DSP's laws; a voice is never cut, every end fades) and there is no peak limiter. The engine is a DRAM unit in the platform reserve; the page is a pinned ROM cave at the start of the second free gap whose FM SYNTH descriptor is a runtime clone of the stock FLEX record (built in the unit's RAM on first use: no stock bytes in the repository). [`modules/synth/README.md`](../../../modules/synth/README.md).
- **SY DRUM** — a drum machine in the same machine list, the row after FM SYNTH (SELECT MACHINE TYPE scrolls to it): one voice a track, two oscillators, a sweep, a filter opened by the decay, six modes; PTCH MODE WDTH SWEP SPED DEC on its PLAYBACK page (stock p-locks, LFOs and scenes), a dedicated LFO / S&H (LSPD LDEP WAVE S&H) on its PLAYBACK SETUP page, each lockable per step in GRID and LIVE RECORDING and saved in `sylockNN` files beside the banks. It runs on SYNTH MACHINE's engine (one DRAM unit, a 2 MiB lock table in the platform reserve). Modelled on the 1979 Pearl Syncussion SY-1; not affiliated with or endorsed by Pearl or Behringer; Syncussion is a trademark of its owner. [`modules/sy-drum/README.md`](../../../modules/sy-drum/README.md).
- **SCALE QUANTIZER** — a SCALE row (OFF, then 24 scales), a ROOT row (C .. B, since 2.9) and a GLIDE row (OFF, 1..127) in PROJECT > CONTROL > SEQUENCER: the PTCH knob, its parameter locks and the CHROMATIC trig keys snap to the scale built on the root, key 1 of the keyboard sounds the root, a sample track's keyboard plays the root-to-root octave; GLIDE is the slide time of the synth's and a sample track's legato. Since 2.13 a MIDI track's NOTE knob, NOTE locks and MIDI CHROMATIC keyboard follow SCALE and ROOT too (chord notes, TRAN, the arpeggiator's own notes and MIDI IN stay stock). SCALE, GLIDE and ROOT are battery-RAM bytes (`0x100b14ec` / `0x100b14ed` / `0x100b14ee`), so they survive a power cycle like the stock project settings. One DRAM unit in the platform reserve, a 192-byte ROM core and two pinned ROM stubs, detours, pokes and a `TableGrow` for the menu rows. [`modules/quantizer/README.md`](../../../modules/quantizer/README.md).
- **DIRECT JUMP** — CHAIN AFTER's unused value 1 becomes DIRECT (option 2 of the list in PROJECT > CONTROL > SEQUENCER): a pattern chosen while the sequencer runs takes over at the next step boundary, at the step count the old pattern had reached, the Analog Four / Rytm direct jump. One ROM cave on the pattern-queue setter and the tick handler, four fixed pokes. [`modules/direct-jump/README.md`](../../../modules/direct-jump/README.md).
- **USB MIDI** and **USB AUDIO OUT TRACKS MAIN CUE**: a class-compliant MIDI port and a 20-channel 44.1 kHz 24-bit input on the host (tracks 1–16, MAIN 17–18, CUE 19–20; at full speed the stereo sum), as in [`usb-out-tracks-main-cue`](../../test/usb-out-tracks-main-cue/README.md); the synth's engine, the quantizer, the tuner and the USB units share one runtime.
- **USB AUDIO IN ABCD** and **USB CROSSBAR**: a four-channel 44.1 kHz 24-bit output on the host; host channels 1–4 arrive on inputs A, B, C and D in place of the jacks while the host has the stream open, and the jacks are back when it closes. High speed only (a full-speed host is not offered it); it takes its clock from the 20-channel output (implicit feedback). USB CROSSBAR lets the USB controller go first on the memory crossbar, without which the input loses packet tails under a busy project. As in [`usb-io-tracks-main-cue-abcd`](../../test/usb-io-tracks-main-cue-abcd/README.md); [`modules/usb-audio-in`](../../../modules/usb-audio-in/README.md#abcd).
- **Thirteen stock effects**: every stock FX1 / FX2 effect but SPATIALIZER, whose DSP words hold the USB input's inject.
- **TUNER** — hold **UP** and press **TEMPO**: a window for the current audio track with the note, octave, a ±50 cent needle and Hz, from the track's post-FX pre-fader audio, detected on the ColdFire (McLeod NSDF + YIN refine, integer only) in the UI task; TEMPO, YES, NO or UP + TEMPO again close it, and TEMPO alone, FUNC + TEMPO (tap tempo) and UP alone stay stock. One DRAM unit, three detours, no ROM cave. [`modules/tuner/README.md`](../../../modules/tuner/README.md).
- **PROCESSOR LOAD** — press TEMPO: the popup's top left corner shows the ColdFire's audio-interrupt load, the mean over the last quarter second (`47%`, `!` from 70 %, `--%` without a fresh reading; FUNC held: the longest block of the quarter second), timed on DMA timer 3 at CF METER's two frame-interrupt sites. One DRAM unit, four detours, one poke. [`modules/processor-load/README.md`](../../../modules/processor-load/README.md).

## Octatrick 2.10 .. 2.14 (the pin `v2.9` -> `v2.14`)

- **FM SYNTH in the machine list** (2.10): the sixth row of SRC SETUP and SELECT MACHINE TYPE on every track, no sample and no marker file (the chooser adapted from Modwerk's FM Synth module, MIT); stored as FLEX with `F`, `M`, 1 in the NEIGHBOR column, so a build without it reads a plain FLEX track (choose FLEX or STATIC before downgrading). The marker files still work.
- **The synth** (2.10): DEC 127 = HOLD (0 the shortest decay, 1..126 unchanged); no note-start click (attacks of at least one carrier period, S-shaped); the LFO destination list names the FM page's parameters; a held CHROMATIC key sustains and releases at the key-up; three fixes after Tim's test of the 2.10 engine on his MKI in a Modwerk test image (a restarted note at a short DEC, a second key in a fading paraphonic voice, a live-recorded legato phrase); 6 dB of headroom (VOL 0 the reference, VOL up to about +6 clean).
- **The machine list for more than one machine** (2.11): the rows after PICKUP are a table filled per remix, the row-count pokes are detours reading the count, SELECT MACHINE TYPE scrolls; with FM SYNTH alone the lists and the engine are 2.10's. SYNTH MACHINE declares the conflict with ANALOG BD (the same chooser sites).
- **SY DRUM** and **PROCESSOR LOAD** (2.11), above. The quantizer reads a SY DRUM track as a synth track (semitone PTCH, the keys, MIDI), mono.
- **Two fixes** (2.12) after Tim's test of the 2.11 engine on his MKI: the metronome no longer cuts a held note (the engine had hooked the metronome's click word, `0x46c80350` cleared at `0x4000b2c8`, as a STOP; the hook is gone, that site is stock, the click still sounds, STOP still ends the voices at the stock voice kill); a machine change to or from FM SYNTH or SY DRUM (either list or a marker file) resets the track's machine parameters (PLAYBACK, PLAYBACK SETUP, AMP, LFO and their SETUP pages) to the new machine's init, step and scene locks kept as in the stock firmware, FX slots kept. A grid step, a held key and a live-recorded trig of the same note at the same VOIC measured equal (within 0.01 dB). Everything else plays as on 2.11.
- On hardware: the 2.10 engine (8 Oct 2026) and the 2.11 modules (10 Oct 2026) on Tim's MKI, in Modwerk test images, not in an octabam build (MAIN OS SHA-256 `161d781d…` for 2.10; FM SYNTH `248d987e…`, SY DRUM with FM SYNTH `b9b65cd9…`, PROCESSOR LOAD `f3ebd1c5…` for 2.11). 2.10's later fixes and its 6 dB are emulator-verified; 2.12, 2.13 and 2.14 were reported working on the same MKI on 13 Oct 2026, in this remix as OCTATRICK 2.14 (MAIN OS SHA-256 `c367d8bc…`, byte for byte this tree's bus) and in Modwerk test images (FM Synth 0.1.5 `37661aee…`; SY DRUM 0.1.0 with FM Synth 0.1.5 `27c213b2…`); SY DRUM's bank-file guard is emulator-verified.
- **SCALE QUANTIZER on the MIDI tracks** (2.13): with a scale on, the NOTE knob (the Part's value) and NOTE locks (GRID, and the lock a NOTE turn writes in LIVE RECORDING) step by scale degree from ROOT; the MIDI CHROMATIC keyboard plays the scale from ROOT (key 1 = the root; the readout `A 3` where stock reads `3`); the note-on, the arpeggiator fed by the keys and the note-off carry the snapped note. NOT2..4, TRAN, the arpeggiator's own notes, MIDI IN, scene locks and the LFOs stay stock (a drum machine on a MIDI track keeps its notes; stock's ARP SETUP > KEY forces a track into a key). SCALE OFF is stock. Three new hooks; the NOTE knob's sits one step before the store `0x4005538a`, which MIDI SCENES detours, so the two can share a remix (`octabam-bus`, `octabam-core` and `octabam-inserts` carry both; the ledger accepts the pair).
- **The MIDI CHROMATIC freeze fixed** (2.13): from 2.9 to 2.12 entering CHROMATIC on a MIDI track froze the unit (the drawer's octave hook at `0x400449b8`; stock's MIDI branch jumps past it to `0x400449be`); 2.13 hooks the common push `0x400449be`, the form the Modwerk contributors found ([repeat98/modwerk](https://github.com/repeat98/modwerk) #264, MIT).
- **SY DRUM's step locks kept over a power-off without SAVE** (2.14, SY DRUM only): on Tim's MKI the PLAYBACK SETUP locks were sometimes missing after a power-off with no SAVE PROJECT while the PLAYBACK locks came back. Stock keeps the current bank in battery-backed memory and writes its own working files only while the sequencer is stopped; the step locks' `sylockNN.work` was written by that same save, so a power-off while playing, or within about a second of STOP, found it behind. It is now also written while the sequencer plays (at most once every 60 UI ticks, only while a lock edit is unwritten; one detour more, at the UI tick's transport test `0x4005224a`); an edit made less than about 1.2 s before a power-off can still be lost, SAVE PROJECT closes that. And the lock files are now read whenever a project loads: before, one stock bank file of the project missing, cut short or damaged (stock shows its message and starts that bank empty) left every bank without its step locks. The synth, the quantizer, DIRECT JUMP, TUNER and PROCESSOR LOAD are 2.13's.

## Octatrick 2.9 (the pin `v2.8` -> `v2.9`)

- **ROOT** (C .. B) under SCALE, a battery-RAM byte (`0x100b14ee`, saved as `#SEQUENCER_ROOT`): the scale is built on it -- the knob, the locks, the CHROMATIC keys and the synth's chord snap read one root-rotated mask; key 1 of the CHROMATIC keyboard sounds the root and the readout names it; a sample track's keyboard plays the one complete root-to-root octave, the other position the partial octave on the side that clamps fewer keys. ROOT C is 2.8's behaviour byte for byte; SCALE OFF ignores it.
- **The quantizer is a DRAM unit**: `quantizer.s` moves into the platform runtime beside the synth's engine; the OS image keeps a 192-byte core (the boot clamps, the defaults, the mask) and the two pinned stubs. The ROM footprint goes from 3,319 B to 243 B, so DIRECT JUMP's cave fits beside everything in the zero run again (CF METER's clone included).
- **FINE 0c** the moment a track becomes a synth track: the assigner's three sites and the file browser's load (a first-ever load into a new project included) reset the stock RATE byte from its +63c default; a FINE the user set survives SAVE / reload / re-assign.
- **No limiter**: the per-frame peak limiter is removed, the sum is clamped; the 1/sqrt(VOIC) level law stays (a 4-note chord about -10 dBFS).
- **The engine owns the AMP envelope**: the DSP is shown an always-open envelope on a synth track and the engine applies ATK / HOLD / REL from the AMP page (locks, scenes, LFOs) with the DSP's laws as measured (ATK linear, HOLD a timer from the START, REL exponential, floored at 1 ms; 127 = INF). A voice is never cut: a re-press continues the oscillator from its level, a faded note starts from silence over 16 frames, a stolen voice fades over 3 ms, a VOIC change hands the sounding tone over, STOP kills at the stock voice kill. The held-chord crackle and the note-start pop (the old cold START cutting the still-sounding tone) are gone.
- **Sequencer trigs on a sounding note** are delivered to the DSP in the panel key's form (`po_retrig`), so the DSP keeps its voice instead of crossfading a second one over the engine's single stream: the +5.6 dB bump at every trig on a still-audible note is gone (x24.8 -> x1.01 the tone's slope).
- **The index ramp**: a warm START ramps the FM index envelope from its current value over 16 frames instead of resetting it to the peak (x7.5 -> x1.07).
- Cost against 2.8 (static count): +6 instructions a sample a voice in the FM loops with the limiter's per-sample stage gone, about +15-20 % of a VOIC 1 synth track's frame work, ~0.1-0.2 % of the frame budget; the platform reserve and FREE MEM unchanged; the ROM section about 3 KB smaller, the DRAM append a few KB larger.
- Known limit: a MACHINE change while a REL INF note sounds leaves it sounding until the next key.

## Octatrick 2.8 (the pin `v9.1` -> `v2.8`)

- **MIDI IN** plays a synth track like the CHROMATIC keys: one voice a note up to VOIC, a note-off releases that note, the full 20..127 range, chord memory with a CHRD shape; sample tracks stock.
- **Chord recording with inversions**: a chord fingered on the keys or over MIDI during live recording is recorded as PTCH (the bass) / CHRD (the shape and its inversion) / VOIC (the voices heard) locks on the first key's step; keys within a rolling 150 ms join, a legato hand-over (the earlier key lifted within 50 ms) records single notes, two keys in one panel scan both sound, and one key is one voice (a key bounce no longer doubles a note).
- **LEG** on every audio track's AMP SETUP page (FUNC + AMP), a Part byte saved with the project: OFF / MONO on a sample track, OFF / MONO / POLY on a synth track. MONO is legato at VOIC 1, POLY at any VOIC (a key over a held chord slides the chord to its new voicing, no retrigger, recorded as a trigless trig); GLIDE is the slide time only.
- **Sample-track glide**: a FLEX or STATIC track with LEG MONO and GLIDE slides every pitch change (a legato key, a trigless trig's PTCH lock, the knob, an LFO) over the GLIDE time; a sample trig starts at its own pitch. The STATIC renderer entry is repointed beside the FLEX one for it.
- **Step transpose**: in GRID RECORDING a held trig + FUNC + DOWN / UP moves that step's PTCH lock an octave (every held trig, clamped -64..+63, in any trig mode); with no trig held FUNC + UP / DOWN is still the trig-mode selector.
- **TUNER**, the fourth module (its own remix in Tim's tree; here part of `octatrick`).
- **SCALE and GLIDE in battery RAM**: a power cycle reads no project file (the unit comes back from its battery RAM), so the two bytes moved out of the OS image; the quantizer's `glide.s` is gone and two `jsr` detours clamp them where stock sanitises its own settings block. OCTATRICK9 loses them at a power cycle, 2.8 keeps them.
- **The chord list in Syntakt order** (the triads, the sevenths and adds, the rest, the two-note intervals last); a CHRD byte saved by 2.7 or earlier names another shape.
- Fixes: the synth's FM SYNTH page descriptor is a runtime clone of the stock record (no stock bytes in the repository); the tuning system (PTCH in semitones, RATE as FINE in cents, exact recorded locks, the CHROMATIC octave -4..+4 on a synth track); the quantizer's VOIC read on every track; the marker file's length no longer ends the note.

## Build and flash

1. Set up the repository and the stock OS: [BUILDING.md](../../../docs/guide/BUILDING.md) sections 0–2 (what to install first, then `make setup`, `make emu-setup`, `make os`, `make recon`); clone with `--recurse-submodules` or run `git submodule update --init` so `modules/*/upstream` is populated.
2. Build:

   ```bash
   make image REMIX=octatrick BUILD=1
   ```

   Optional first: `make emu-cf` then `make check REMIX=octatrick`.
3. Back up the card and flash from it: [BUILDING.md](../../../docs/guide/BUILDING.md) sections 4–5. Recovery: section 7. Power-cycle the unit fully after the upgrade, and SAVE or SYNC TO CARD after changing project settings (DIRECT is a project setting; SCALE, ROOT and GLIDE live in battery RAM).
4. USB on a host: [`usb-out-tracks-main-cue`](../../test/usb-out-tracks-main-cue/README.md) — Using it. The computer's audio: pick the Octatrack's four-channel output on the host; channels 1–4 play into inputs A–D (record them, or monitor them through the mixer's DIR settings, as a jack input).
