# `octabam-full`

`octabam` as of `5f8e779f` (1 Nov 2026), before TRANSIENT, DISTORX and SIDECHAIN_COMPRESSOR were left out of
[`octabam`](../../octabam/README.md) for 0.1: all six demand-loaded effects, SC LOAD METER BRIDGE, and the
loader's homes for them.

`make check REMIX=octabam-full`.

**Hardware:** image `OCTABAMS1` (this remix, 1 Nov 2026), Sam's MKII. A program change from BASE to FILTER FX2 def
stopped the DSP frame loop (`docs/contributing/FAILURE_MODES.md`).
