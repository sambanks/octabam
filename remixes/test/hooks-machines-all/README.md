# hooks-machines-all (test remix)

OCTA303, WAVE CF and CX OSC in one image: HOOKS gives the track's machine list eight rows, OCTA-303 on row 5, WAVE on row 6 and CX OSC on row 7, and the list scrolls. See [HOOKS](../../../modules/hooks/README.md) (`machine_rows`).

`tools/verify/verify_hooks.py hooks-machines-all` checks the bridged sites in this image after
`make bus REMIX=hooks-machines-all`.
