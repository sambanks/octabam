# `octatrick` — Tim Hastie's four modules with USB MIDI and USB audio out and in on the stock effects

One remix with everything: SYNTH MACHINE, SCALE QUANTIZER, DIRECT JUMP and TUNER from [timhastie/octatrick-modules](https://github.com/timhastie/octatrick-modules) (the submodule under `modules/synth`, `modules/quantizer`, `modules/direct-jump` and `modules/tuner`, pinned to `v2.9` (`525f4b1`) = Octatrick 2.9, 29 Sep 2026), with USB MIDI and USB AUDIO OUT TRACKS MAIN CUE (markandrus, [octemu](https://github.com/markandrus/octemu); the 20-channel output as it is on main today) and USB AUDIO IN ABCD with USB CROSSBAR (Bryan T: the computer's audio comes in on inputs A, B, C and D). No octabam DSP code: thirteen of the fourteen stock effects are listed with fallback NONE, the `usb-io-tracks-main-cue-abcd` pattern, so their DSP code, their dispatch and their chooser rows stay stock. SPATIALIZER is gone from both effect menus because the USB audio input needs a few of a stock effect's DSP words for its inject and takes SPATIALIZER's, as Sam's `usb-io` remixes do; a project that selects it plays that slot as NONE. Until 29 Sep 2026 this was three remixes (`octatrick`, `octatrick-usb`, `octatrick-tuner`); the subsets served nobody, so they are one.

## What is in it

- **SYNTH MACHINE** — any FLEX track whose sample is named FMSYNTH*.wav (a silent 4 s marker file will do; SYNTH*.wav is still accepted, and the marker's length never ends the note) plays a two-operator FM voice instead of the sample: PLAYBACK page PTCH RATO INDX FINE FDBK DEC (PTCH in semitones, FINE in cents), on the LFO page VOIC (1 = mono, 2..4 = paraphonic) and CHRD (32 chord shapes, each with three inversions on the knob, lockable per step, snapped onto SCALE and its ROOT). Since 2.9 the engine owns the AMP envelope (ATK / HOLD / REL from the AMP page, applied with the DSP's laws; a voice is never cut, every end fades) and there is no peak limiter. The engine is a DRAM unit in the platform reserve; the page is a pinned ROM cave at the start of the second free gap whose FM SYNTH descriptor is a runtime clone of the stock FLEX record (built in the unit's RAM on first use: no stock bytes in the repository). [`modules/synth/README.md`](../../modules/synth/README.md).
- **SCALE QUANTIZER** — a SCALE row (OFF, then 24 scales), a ROOT row (C .. B, since 2.9) and a GLIDE row (OFF, 1..127) in PROJECT > CONTROL > SEQUENCER: the PTCH knob, its parameter locks and the CHROMATIC trig keys snap to the scale built on the root, key 1 of the keyboard sounds the root, a sample track's keyboard plays the root-to-root octave; GLIDE is the slide time of the synth's and a sample track's legato. SCALE, GLIDE and ROOT are battery-RAM bytes (`0x100b14ec` / `0x100b14ed` / `0x100b14ee`), so they survive a power cycle like the stock project settings. One DRAM unit in the platform reserve, a 192-byte ROM core and two pinned ROM stubs, detours, pokes and a `TableGrow` for the menu rows. [`modules/quantizer/README.md`](../../modules/quantizer/README.md).
- **DIRECT JUMP** — CHAIN AFTER's unused value 1 becomes DIRECT (option 2 of the list in PROJECT > CONTROL > SEQUENCER): a pattern chosen while the sequencer runs takes over at the next step boundary, at the step count the old pattern had reached, the Analog Four / Rytm direct jump. One ROM cave on the pattern-queue setter and the tick handler, four fixed pokes. [`modules/direct-jump/README.md`](../../modules/direct-jump/README.md).
- **USB MIDI** and **USB AUDIO OUT TRACKS MAIN CUE**: a class-compliant MIDI port and a 20-channel 44.1 kHz 24-bit input on the host (tracks 1–16, MAIN 17–18, CUE 19–20; at full speed the stereo sum), as in [`usb-out-tracks-main-cue`](../test/usb-out-tracks-main-cue/README.md); the synth's engine, the quantizer, the tuner and the USB units share one runtime.
- **USB AUDIO IN ABCD** and **USB CROSSBAR**: a four-channel 44.1 kHz 24-bit output on the host; host channels 1–4 arrive on inputs A, B, C and D in place of the jacks while the host has the stream open, and the jacks are back when it closes. High speed only (a full-speed host is not offered it); it takes its clock from the 20-channel output (implicit feedback). USB CROSSBAR lets the USB controller go first on the memory crossbar, without which the input loses packet tails under a busy project. As in [`usb-io-tracks-main-cue-abcd`](../test/usb-io-tracks-main-cue-abcd/README.md); [`modules/usb-audio-in`](../../modules/usb-audio-in/README.md#abcd).
- **Thirteen stock effects**: every stock FX1 / FX2 effect but SPATIALIZER, whose DSP words hold the USB input's inject.
- **TUNER** — hold **UP** and press **TEMPO**: a window for the current audio track with the note, octave, a ±50 cent needle and Hz, from the track's post-FX pre-fader audio, detected on the ColdFire (McLeod NSDF + YIN refine, integer only) in the UI task; TEMPO, YES, NO or UP + TEMPO again close it, and TEMPO alone, FUNC + TEMPO (tap tempo) and UP alone stay stock. One DRAM unit, three detours, no ROM cave. [`modules/tuner/README.md`](../../modules/tuner/README.md).

## Octatrick 2.9 (the pin `v2.8` -> `v2.9`)

- **ROOT** (C .. B) under SCALE, a battery-RAM byte (`0x100b14ee`, saved as `#SEQUENCER_ROOT`): the scale is built on it -- the knob, the locks, the CHROMATIC keys and the synth's chord snap read one root-rotated mask; key 1 of the CHROMATIC keyboard sounds the root and the readout names it; a sample track's keyboard plays the one complete root-to-root octave, the other position the partial octave on the side that clamps fewer keys. ROOT C is 2.8's behaviour byte for byte; SCALE OFF ignores it.
- **The quantizer is a DRAM unit**: `quantizer.s` moves into the platform runtime beside the synth's engine; the OS image keeps a 192-byte core (the boot clamps, the defaults, the mask) and the two pinned stubs. The ROM footprint goes from 3,319 B to 243 B, so DIRECT JUMP's cave fits beside everything in the zero run again (CF METER's clone included).
- **FINE 0c** the moment a track becomes a synth track: the assigner's three sites and the file browser's load (a first-ever load into a new project included) reset the stock RATE byte from its +63c default; a FINE the user set survives SAVE / reload / re-assign.
- **No limiter**: the per-frame peak limiter is removed, the sum is clamped; the 1/sqrt(VOIC) level law stays (a 4-note chord about -10 dBFS).
- **The engine owns the AMP envelope**: the DSP is shown an always-open envelope on a synth track and the engine applies ATK / HOLD / REL from the AMP page (locks, scenes, LFOs) with the DSP's laws as measured (ATK linear, HOLD a timer from the START, REL exponential, floored at 1 ms; 127 = INF). A voice is never cut: a re-press continues the oscillator from its level, a faded note starts from silence over 16 frames, a stolen voice fades over 3 ms, a VOIC change hands the sounding tone over, STOP kills at the stock voice kill. The held-chord crackle and the note-start pop (the old cold START cutting the still-sounding tone) are gone.
- **Sequencer trigs on a sounding note** are delivered to the DSP in the panel key's form (`po_retrig`), so the DSP keeps its voice instead of crossfading a second one over the engine's single stream: the +5.6 dB bump at every trig on a still-audible note is gone (x24.8 -> x1.01 the tone's slope).
- **The index ramp**: a warm START ramps the FM index envelope from its current value over 16 frames instead of resetting it to the peak (x7.5 -> x1.07).
- Cost against 2.8 (static count): +6 instructions a sample a voice in the FM loops with the limiter's per-sample stage gone, about +15-20 % of a VOIC 1 synth track's frame work, ~0.1-0.2 % of the frame budget; the platform reserve and FREE MEM unchanged; the ROM section about 3 KB smaller, the DRAM append a few KB larger.
- Known limit: a MACHINE change while a REL INF note sounds leaves it sounding until the next key.

## Octatrick 2.8 (the pin `v9.1` -> `v2.8`)

- **MIDI IN** plays a synth track like the CHROMATIC keys: one voice a note up to VOIC, a note-off releases that note, the full 20..127 range, chord memory with a CHRD shape; sample tracks stock.
- **Chord recording with inversions**: a chord fingered on the keys or over MIDI during live recording is recorded as PTCH (the bass) / CHRD (the shape and its inversion) / VOIC (the voices heard) locks on the first key's step; keys within a rolling 150 ms join, a legato hand-over (the earlier key lifted within 50 ms) records single notes, two keys in one panel scan both sound, and one key is one voice (a key bounce no longer doubles a note).
- **LEG** on every audio track's AMP SETUP page (FUNC + AMP), a Part byte saved with the project: OFF / MONO on a sample track, OFF / MONO / POLY on a synth track. MONO is legato at VOIC 1, POLY at any VOIC (a key over a held chord slides the chord to its new voicing, no retrigger, recorded as a trigless trig); GLIDE is the slide time only.
- **Sample-track glide**: a FLEX or STATIC track with LEG MONO and GLIDE slides every pitch change (a legato key, a trigless trig's PTCH lock, the knob, an LFO) over the GLIDE time; a sample trig starts at its own pitch. The STATIC renderer entry is repointed beside the FLEX one for it.
- **Step transpose**: in GRID RECORDING a held trig + FUNC + DOWN / UP moves that step's PTCH lock an octave (every held trig, clamped -64..+63, in any trig mode); with no trig held FUNC + UP / DOWN is still the trig-mode selector.
- **TUNER**, the fourth module (its own remix in Tim's tree; here part of `octatrick`).
- **SCALE and GLIDE in battery RAM**: a power cycle reads no project file (the unit comes back from its battery RAM), so the two bytes moved out of the OS image; the quantizer's `glide.s` is gone and two `jsr` detours clamp them where stock sanitises its own settings block. OCTATRICK9 loses them at a power cycle, 2.8 keeps them.
- **The chord list in Syntakt order** (the triads, the sevenths and adds, the rest, the two-note intervals last); a CHRD byte saved by 2.7 or earlier names another shape.
- Fixes: the synth's FM SYNTH page descriptor is a runtime clone of the stock record (no stock bytes in the repository); the tuning system (PTCH in semitones, RATE as FINE in cents, exact recorded locks, the CHROMATIC octave -4..+4 on a synth track); the quantizer's VOIC read on every track; the marker file's length no longer ends the note.

## Status

- OCTATRICK9 on Tim's MKI (26 Sep 2026; the remix was then `octatrick-usb`): the synth, the quantizer and direct jump work; USB audio streams all 20 channels (tracks 1–16, MAIN 17–18, CUE 19–20) — the first MKI run of the USB stream. MAIN/CUE were silent until a full power-off after the OS upgrade; power-cycle after flashing. Every test build 2.3 .. 2.8 since was flashed on the same unit from Tim's tree ([timhastie/octatrick](https://github.com/timhastie/octatrick), the same wrappers over the same submodule).
- The 2.9 line up to the build before its last two fixes (ROOT, the DRAM quantizer, FINE 0c, the envelope engine, no limiter) ran on the same MKI: the held-chord crackle and the live-key pops gone, by ear. The last two fixes (the sequencer trigs, the index ramp) are emulator-verified only.
- `v2.9` on this tree, this selection (the current USB modules, USB AUDIO IN ABCD included): `make check REMIX=octatrick` passes every gate, `verify_usb` and `verify_usb_in` among them (BUILD 40, 29 Sep 2026); the 2.8 and 2.9 features were measured in the ColdFire port through the virtual panel, feature by feature, in `modules/synth/upstream/synth/README.md` and `modules/quantizer/upstream/quantizer/README.md`. Flashed on Tim's MKI as test build 3.0 b40 (next item).
- Test build 3.0 b40 (this remix at BUILD 40) on Tim's MKI, 29 Sep 2026: USB AUDIO IN works in a one-minute check, the Mac's audio arriving on the inputs and playing normally -- the first run of this USB input on an MKI. Long runs are not yet tested there. The tuner (UP + TEMPO) works on the same build.
- At `v9.1` the images built here were byte-identical to the images Tim flashed, and byte-identical whether the module sources sit in `modules/<name>/` directly or under the submodule (the wrapper executes the same manifest). The submodule's history is a single clean root (`42877ad`, `237d40b`, then `525f4b1`): no commit carries stock OS bytes (`tools/stock_scan.py` in the submodule checks every data directive against the user's own image).
- Direct jump under PER TRACK scales and across Parts was measured in the emulator (41 jumps; three Parts); the two limits found are in `modules/direct-jump/upstream/direct-jump/README.md`.
- Not carried together with `tempo-bus` (both use the second free ROM gap; the ledger refuses the pair).

## Build and flash

1. Set up the repository and the stock OS: [BUILDING.md](../../docs/guide/BUILDING.md) sections 0–2 (what to install first, then `make setup`, `make emu-setup`, `make os`, `make recon`); clone with `--recurse-submodules` or run `git submodule update --init` so `modules/*/upstream` is populated.
2. Build:

   ```bash
   make image REMIX=octatrick BUILD=1
   ```

   Optional first: `make emu-cf` then `make check REMIX=octatrick`.
3. Back up the card and flash from it: [BUILDING.md](../../docs/guide/BUILDING.md) sections 4–5. Recovery: section 7. Power-cycle the unit fully after the upgrade, and SAVE or SYNC TO CARD after changing project settings (DIRECT is a project setting; SCALE, ROOT and GLIDE live in battery RAM).
4. USB on a host: [`usb-out-tracks-main-cue`](../test/usb-out-tracks-main-cue/README.md) — Using it. The computer's audio: pick the Octatrack's four-channel output on the host; channels 1–4 play into inputs A–D (record them, or monitor them through the mixer's DIR settings, as a jack input).
