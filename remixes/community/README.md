# Community remixes

A contributor's own selection of modules for a card: the image they flashed, or a combination they use. Each is `community/<name>/` with `remix.py` and a `README.md` saying where it has run; the name is the contributor's or the remix's purpose, never `octabam-` (CONTRIBUTING.md "Remixes"). Rendered by `make docs`; the project's own remixes are [one level up](../README.md).
