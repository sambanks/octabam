# cx-poly

Same modules and settings as `cx`, with CX OSC **VOICES=POLY**.

The LFO page shows Tim **VOIC 1..4** and **CHRD** in place of LFO 3
**SPD3** and **DEP3**. The `cx` remix remains mono. POLY allows four CX OSC
tracks per Part; MONO allows six.

USB TRACKS OFF / MAIN 1 / CUE 0 / MASTER 0 / IN OFF. MUTE_MODES PLACE=DRAM.
