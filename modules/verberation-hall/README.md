# `verberation-hall` — VERB HALL

[VERBERATION](../verberation/README.md) on DARK REV's id `0x16`, starting in **HALL** mode: the chooser row
"Verb Hall" (`VBHL`), whose defaults are HALL's voicing and whose MODE is 2. It has no DSP code of its own:
`MenuEntry(dsp_of="VERBERATION")` points its id at VERBERATION's init and proc on both payloads, so it is
VERBERATION in every way but its name and starting point, MODE included. It takes DARK REV's place
(`replaces="DARK REV"`), so in a remix that carries it a Part saved with DARK REV opens on this row.

Built in [`octabam-verbs`](../../remixes/octabam-verbs/README.md). Knobs, modes, measurements and costs are
VERBERATION's. Not run on a unit.
