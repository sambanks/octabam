# `quantize-live-rec-toggle` -- QUANTIZE_LIVE_REC_TOGGLE

QUANTIZE LIVE REC from the front panel: hold `[REC]` and tap `[PLAY]` to show the setting in a toast (`LIVE REC: QUANTIZED` or `LIVE REC: UNQUANTIZED`); tap `[PLAY]` again while the toast is up to invert it. With PERSONALIZE open, its check mark follows. The first `[REC]` + `[PLAY]` still starts live recording as on stock.
