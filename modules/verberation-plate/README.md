# `verberation-plate` — VERB PLATE

[VERBERATION](../verberation/README.md) on PLATE REV's id `0x14`, starting in **PLATE** mode: the chooser row
"Verb Plate" (`VBPL`), whose defaults are PLATE's voicing and whose MODE is 1. It has no DSP code of its own:
`MenuEntry(dsp_of="VERBERATION")` points its id at VERBERATION's init and proc on both payloads, so it is
VERBERATION in every way but its name and starting point, MODE included. It takes PLATE REV's place
(`replaces="PLATE REV"`), so in a remix that carries it a Part saved with PLATE REV opens on this row.

Built in [`octabam-verbs`](../../remixes/octabam-verbs/README.md). Knobs, modes, measurements and costs are
VERBERATION's. Not run on a unit.
