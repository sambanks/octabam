# `verberation-room` — VERB ROOM

[VERBERATION](../verberation/README.md) on SPRING REV's id `0x15`, starting in **ROOM** mode: the chooser row
"Verb Room" (`VBRM`), whose defaults are ROOM's voicing and whose MODE is 0. It has no DSP code of its own:
`MenuEntry(dsp_of="VERBERATION")` points its id at VERBERATION's init and proc on both payloads, so it is
VERBERATION in every way but its name and starting point, MODE included. It takes SPRING REV's place
(`replaces="SPRING REV"`), so in a remix that carries it a Part saved with SPRING REV opens on this row.

Built in [`octabam-verbs`](../../remixes/octabam-verbs/README.md). Knobs, modes, measurements and costs are
VERBERATION's. Not run on a unit.
