# `rec-trig-mute` -- REC_TRIG_MUTE

Mute a track's recorder trigs without deleting them. Hold `[TRACK]` and press `[REC]`: that track's recorder trigs stop firing -- a recording already running finishes -- and a toast reads `REC TRIGS MUTED`. Press it again to bring them back (`REC TRIGS UNMUTED`). Each track keeps its own state: with several track keys held, each one flips (`REC TRIGS TOGGLED` when they end up mixed). The toast stays up while the track key is held, up to 1 s, and closes when it is let go. While a track key is held, `[REC]` does not switch grid recording; on its own `[REC]` is stock. Any screen; it holds across pattern changes until you unmute, and every track starts unmuted at power-on. A muted track's tab at the screen edge shows two dots stacked beside its machine letter, on the inner side (right of the letter on T1-T4, left of it on T5-T8); the play/stop icon below is stock. MIDI CC 80: 0 unmutes, 1-127 mutes, on a track's channel (AUTO channel = the active track), with AUDIO CC IN on; the keys send CC 80 (1 muted / 0 unmuted) on each held track's channel, with AUDIO CC OUT on. `[TRACK]` + `[YES]` / `[NO]` and `[FUNC]` + `[YES]` / `[NO]` stay stock.

Built from [Zac-Kyoti/octatrack-kyoti-fw](https://github.com/Zac-Kyoti/octatrack-kyoti-fw)
(submodule `upstream/`, pinned to `91a58e9`). `Kind.CF_PATCH`. One DRAM unit (`patch_rec_trig_mute.s`, built with `--defsym OCTABAM_UNIT`), five detours, four `SymbolRef`s (the T1 / T2 keymaps' `[REC]` records; `rtm_rec` hands every event but a track-held press back to stock's `0x40048774`, so STEM REC's detour there still runs).
